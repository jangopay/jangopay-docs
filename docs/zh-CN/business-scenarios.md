# 业务场景

根据客户购买的内容，以及商户如何交付订单，选择收款流程。

| 业务 | 付款用途 | 需要连接的交付环节 |
| :--- | :--- | :--- |
| AI 与 SaaS | 会员、订阅权益或使用额度 | 开通权益或增加额度 |
| 数字内容 | 源码、授权、插件或下载 | 受控的数字内容交付 |
| 跨境电商 | 店铺结账或单笔外贸订单 | 订单确认与发货流程 |
| 服务器与网络 | 新购、续费或套餐升级 | 服务开通与续期 |
| 游戏与虚拟商品 | 充值套餐或虚拟道具 | 账户充值或道具发放 |
| 充值与卡券 | 礼品卡、话费或电子代金券 | 发码或余额更新 |
| 预订 | 酒店、票务或活动预约 | 确认预订 |
| 平台运营 | 用户余额充值与商户对账 | 平台账本与结算记录 |

## 选择接入深度

- **收款链接：**适合由工作人员核对订单并管理交付的业务。
- **API / Webhook 流程：**适合在验证付款后自动触发业务动作。
- **商户运营：**业务涉及余额、转出与对账时，分别制定对应流程。

支付通知不会自动实现物流、数字交付、周期扣款或平台账本。除非正式产品明确支持，否则这些环节仍由商户系统负责。
