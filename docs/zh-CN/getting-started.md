# 快速开始

## 1. 选择收款方式

需要把付款页面直接分享给客户时，先使用**收款链接**。需要把收款记录与通知接入网站、应用或后台时，再选择 **API 与 Webhook**。

## 2. 创建收款单

从[正式官网](https://www.jangopay.org/)登录，在账户可用的功能中创建收款记录。分享付款页面前，核对金额、订单说明以及支持的币种与网络。

## 3. 引导客户付款

1. 核对金额，选择支持的币种与网络组合。
2. 扫描二维码或复制页面显示的地址。
3. 按付款页提示，使用同一网络完成转账。
4. 等待确认并查看付款结果。

## 4. 确认付款并核对订单

以商户后台或经过验证的正式接入结果为准。客户截图、提交转账或交易广播，不等于业务订单已确认付款。交付前需要核对业务订单与收款记录。

## 5. 准备异常处理

明确如何处理超时、少付、多付、网络不匹配和确认延迟。使用正式支持流程，不假定所有付款都适用同一种退款或资产恢复政策。
