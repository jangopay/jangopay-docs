# 产品能力

JangoPay 官网展示六个产品模块。具体可用能力与设置，以当前产品和你的账户为准。

| 产品 | 主要作用 | 常见流程 |
| :--- | :--- | :--- |
| 收款链接 | 创建并分享托管付款页面 | 无需定制结账页即可收款 |
| API 与 Webhook | 连接收款记录和状态通知 | 同步支付记录与业务订单 |
| 收款管理 | 跟踪收款单与支付状态 | 查看已确认、待处理及异常付款 |
| 资产与转出 | 查看币种余额和转出记录 | 将可用资产转至外部钱包 |
| 自动兑换 | 兑换支持的资产 | 将符合条件的波动资产兑换为稳定币 |
| 客户洞察 | 了解访问、付款与转化 | 查看客户与收款趋势 |

## 统一工作台，不同管理职责

收款记录、资产余额、转出交易与客户指标用途不同。接入自己的系统时，应分别维护标识、状态和核对规则。

## 内容边界

本概览不构成资金托管说明、兑换价格保证、到账时效承诺或完整支持币种清单。开展业务前，应核对正式产品条款、账户设置与支持说明。
